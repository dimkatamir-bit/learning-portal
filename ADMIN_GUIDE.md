# Администратор Learning Portal

Адрес: http://127.0.0.1:8001/admin/ . Вход по email администратора; подтверждение почты для is_staff не требуется.

## Сотрудники

Найдите сотрудника по имени, фамилии или email. В списке видны подтверждение почты, активность, этап и число пройденных модулей. В карточке сотрудника ниже находятся его прогресс и ссылки на попытки тестов и сертификаты. Не выдавайте права администратора обычным учащимся.

## Добавление курса

1. Откройте «Курсы» → «Добавить». Заполните название и описание.
2. Ниже добавьте модули: номер, название и ссылка на видео. Сохраните курс.
3. Через «Изменить» возле модуля откройте его карточку и заполните текст урока.
4. Для 30-секундного фрагмента YouTube ссылка выглядит как https://www.youtube.com/watch?v=VIDEO_ID&end=30 .
5. В списке модулей используйте «Добавить тест» или «Редактировать тест».

## Тесты и ответы

1. В карточке теста выберите курс и модуль, задайте проходной балл. Для финального экзамена отметьте «Финальный экзамен», модуль оставьте пустым.
2. Добавьте вопросы и сохраните тест.
3. Нажмите «Изменить» рядом с вопросом. На странице вопроса добавьте минимум два варианта и отметьте один или несколько правильных.
4. Проверьте столбец «Готов к прохождению» в списке тестов. Незавершённые вопросы блокируют готовность теста.

## Результаты и сертификаты

В разделе «Прогресс» каждый сотрудник показан один раз. Рядом отображаются все начатые курсы: название, цветная полоса, процент и следующий модуль. Четыре сданных модульных теста из пяти — 80%. Цвета: серый — 0%, золотистый — менее 70%, синий — от 70%, зелёный — 100%. Финальный экзамен учитывается отдельно: 100% модулей ещё не означает получение сертификата.

Нажмите на имя сотрудника, чтобы увидеть все модули по каждому курсу, доступность следующего модуля, даты просмотра видео и изучения материала, сдачу тестов и результаты последних попыток. Список можно искать по имени или email и фильтровать по курсу. В карточке пользователя ссылка «Прогресс» открывает эту подробную страницу.

«Попытки экзамена» фильтруются по сотруднику, курсу, результату и дате. «Прогресс» показывает, что уже пройдено. Эти записи доступны для просмотра без ручного изменения оценок.

В «Сертификатах» есть статус PDF, защищённое скачивание и ссылка проверки подлинности. Для скачивания через админку требуется право просмотра сертификатов. Публичная папка media для этого не нужна.

На главной админки находятся быстрые переходы. Длинные списки разделены на страницы; сверху и снизу формы доступны кнопки сохранения.

В карточке сертификата показаны данные получателя, курса и даты, а ниже — встроенный просмотр PDF. Ссылка «Открыть сертификат» показывает PDF в отдельной вкладке. Если файл отсутствует, карточка покажет подсказку о сохранении папки media.
